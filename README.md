# ML Scraper

Gerador de mensagens de WhatsApp para divulgar produtos do Mercado Livre e AliExpress.

## Rodar localmente

Duplo clique em `start.command`.

## Deploy no Render

1. Faça fork/upload deste repositório no GitHub.
2. No [Render](https://render.com), crie um novo Web Service apontando pro seu repo.
3. Defina a variável de ambiente `SENHA_ACESSO` com a senha de acesso.
4. Render lê o `render.yaml` e configura tudo sozinho.
